# 学习模式

适用版本：`plugin/package.json` = **0.9.40** ｜ 2026-11-27
本文合并了《学习计划设计.md》与《学习模式对话设计.md》（两者已在文件头标注为历史），只保留与当前代码一致的结论。需求状态看《[需求台账](./需求台账.md)》，接口看《[工具与路由](./工具与路由.md)》。

## 1. 两套模型并存，边界先分清

| | 现行：学习任务模型（新轨） | 旧：计划模型（旧轨，保留） |
|---|---|---|
| 数据 | `study_tasks` 索引 + 会话工作区 `learning/` | `subjects` / `topics` / `study_plan` 三张表 |
| 页面 | 今日学习、书架、错题集、习惯 | 学习规划页签 |
| 知识内容 | 在工作区 `knowledge.db`，插件不复制 | 只有科目/知识点标题与掌握度，没有知识正文 |
| 谁写 | 学习模式对话（`study_register_task` / `study_run_program` / `study_answer`） | 既有计划可改期与完成 |
| 是否仍在演进 | 是 | **冻结**：只修 bug，不加功能 |

学习规划可为学习任务安排开始时间，并将进行中或待开始的任务拖到一个科目下。拖到另一科目会更新关联，双击任务可以打开设置。原有日程保留在「之前生成的计划」。

看板上的待办和进行中同步学习规划。学习进度达标后，两个面板都显示为当日完成，次日凌晨 4 点开始新的学习日。

## 2. 现行学习任务模型

### 2.1 索引与工作区

- 插件只存索引：`title / workspace_path / template / summary / item_id / session_id / last_done_day / daily_target / daily_new / daily_review`。一个会话最多一条学习任务（`session_id` 唯一索引）。
- 工作区布局：

```text
<会话工作区>/learning/
├─ knowledge.db   知识本体（SQLite）：cards（单词式）或 points（大纲式）
├─ index.md       人读目录 / 学习方式（meta.learning_mode），可直接 write/edit
└─ materials/     study_import_material 复制进来的资料副本
```

- `knowledge.db` **平时只读**（0444），只有 `study_run_program` 执行期间临时解封；因此凡是批量写库、重算签名、导入词条，都必须走 `study_run_program`，不要试图用通用写文件工具改它。
- 学习日按**凌晨 04:00** 切分（不是 0 点），只影响今日学习/每日目标/习惯；日历与提醒不变。

### 2.2 模板

内置 5 个模板，随插件发布，用 `study_template` 取正文（不要去猜磁盘路径）：

三种知识库类型（旧 id 仍作为别名）：

| 类型 | 模板 id | 结构 | 宿主如何出题 |
|---|---|---|---|
| 列表库 | `list`（旧 `word-bank`） | `cards(id, front, back, extra, proficiency, learned, updated_at, …)` | 按 `cards` 表出题 + 干扰项 |
| 知识树 | `tree`（旧 `outline`） | `points(id, title, detail, proficiency, learned, updated_at, …)` | 按 `points` 表出题，无干扰项 |
| 题库 | `bank`（旧 `outline-bank`） | `questions` + `question_points` + `points` | 按 `questions` 表出题：新题 `learned=0`，复习按覆盖的最弱知识点排序；答题同时推进题目与覆盖的知识点 |
- `custom`：自定义表结构，主表仍必须叫 `cards` 或 `points`（复用列表库/知识树的出题逻辑）
- `ingest` / `teaching` **不是知识库类型**：前者是资料入库流程文档，后者是讲解协议；只在 `study_template` 里按需取用

初始熟练度统一为 **4**；已存在的条目不因换模板而重置。

### 2.3 登记流程（对话侧）

1. 先 `study_task_list` 看本会话是否已登记；已登记就读 `workspacePath` 下的 `learning/index.md` 继续。
2. 一次确认三件事：学什么 / 每天多少 / 学习方式与模板。
3. 书架用推荐不用问路径：`study_shelf_list` 取条目，挑 3–5 个最相关的问一次（多选），登记后 `study_attach_shelves`。
4. `study_register_task` 登记（标题=对话标题、`workspacePath`=会话工作区绝对路径、`template`、`dailyNew`、`dailyReview`）。重复登记会更新同一条记录，不会产生第二条。
5. 宿主自动在任务树「学习」根下挂一个镜像节点（类别与标签都是 `学习`）。**删除学习任务会连带删除该节点**；节点每天自动重开，用户不需要（也拿不到）手动勾完成。

### 2.4 出题、批改与熟练度

- `study_next_questions(taskId, count, { newCount, reviewCount })` 一次返回 5–10 题（默认 5，上限 20）：
  **新内容**取 `learned = 0` 的条目，**复习**取已学过的弱项（熟练度升序）；可显式指定两者配比；
  每题带 prompt/answer/options 与 `isNew`。熟练度为 0 的条目**照常出题**，只是 3 天内答对不加分。
- 对话必须把这批题放进**同一次** `ask_user_question`（一题一个 `questions` 项），用户一次交卷后统一批改，逐题 `study_answer(taskId, itemId, verdict)`。
- 题池不足时使用实际可用的不同题目。批改先给正确、部分正确和错误的题量，再逐题复述完整题干、条件和选项，并给出完整正确答案。薄弱题补正确思路、易混点和主动回忆提示。已核对的书架页码和来源可随题呈现。
- 熟练度规则（唯一出处；旧轨的复习间隔另见第 3 节）：

| 规则 | 值 |
|---|---|
| 初始熟练度 | 4 |
| 范围 | 0–10，越界夹紧 |
| 答对 / 答错 | +1 / −1 |
| 部分正确 | 严格判错，适中保持熟练度，宽松判对 |
| 满 10 | 视为掌握：不再出题，并**自动删除该条对应的错题** |
| 降到 0 | **仍每天出题**，但 3 天内答对不加分；3 天后恢复计分（锁定以最后一次作答时间计） |
| `learned` 标记 | 新条目 `0`，首次作答后置 `1`；无该列的旧库按“全部为复习”兼容 |
| 对用户可见性 | 只在库里变化，对话不显示分数、不说 +1/−1 |

### 2.5 每日目标与"今天完成"

- 每个学习任务有两段默认每日目标：`daily_new`（新内容）与 `daily_review`（复习），合计即 `daily_target`；
  `study_set_target(taskId, dailyNew, dailyReview)` 改默认，`study_set_day_target(taskId, newTarget, reviewTarget)` 只改**今天**。
- 进度按 `answered_new` / `answered_review` 分别累计；**两段都达标**（或对应池子已空）才自动完成今天。
- 当天答题数达到目标时，`study_answer` 会自动调用 `study_finish_today` 等价逻辑：完成任务、记 `last_done_day`、清逾期计数。
- 需要提前收尾时由对话显式调 `study_finish_today`；第二天节点自动重新打开，不需要手工新建节点。
- 逾期天数由 `overdueDays` 提供，对话开场应主动指出。

### 2.6 错题集

- 字段：题目、正确答案、错误原因、记忆提示、来源、（可选）科目与标签。双击详情可看完整题干、网址及核对过的 PDF 文件页和印刷页。快速讲解会携带这些信息。
- 写入时必须带 `taskId` 与 `itemId`（知识库里的 `cards.id` / `points.id`），这样错题能按学习任务归类，并能在该条目满 10 时被自动清理。
- 页面支持按任务/日期筛选、双击放大、删除；**默认随机排序**，一旦筛选就按创建时间倒序。
- `mistake.review` 只推后复习时间，不动熟练度。

### 2.7 每周检查（含周学习时间规划）

触发：`meta.last_weekly_check` 距今天 > 7 天，或本周（周一起）还有天没排分钟，或用户主动要求。

预设要求对话**按顺序**完成六步，并把结果写成 ≤6 行周报：

| 步骤 | 内容 | 关键约束 |
|---|---|---|
| A 资料同步 | 比对 `sources` 签名（`md5(内容) + 字节数 + 修改时间`，与 `templates/ingest.md` 一致），新增/变更/上次提取失败的文件重新入库 | 只增量，不重复导入；完成后写 `meta.last_update` |
| B 结构自检 | `PRAGMA table_info(cards/points)`，缺 `learned` 就 `ALTER TABLE` 补列 | 缺其它必需列只报告，**不自动删数据** |
| C 目标复盘 | `study_progress` 按日历史 | 连续 3 天达标 → `dailyNew +1`、`dailyReview +2`；连续 2 天未达标或 `overdueDays ≥ 2` → 各降 20% | 下限 `new ≥ 1`、`review ≥ 2`，总量 ≤ 40；写默认值用 `study_set_target` |
| D 时间规划 | 按 `study_habits` 写整周分钟 | 留空/`null` = 休息，**不要写 0**；只补空白天 |
| E 错题巡检 | 只提醒用户去错题集页面按日期筛选、删除残留 | 对话无错题查询接口，**不许编造数量** |
| F 收尾 | 写 `meta.last_weekly_check`，输出周报 | 失败分项必须写进周报，不静默跳过 |

周报格式：`📅 本周检查` + 资料新增/更新/失败 + 结构修复 + 目标调整 + 本周计划合计 + 待办。

### 2.8 习惯采集

- 学习模式对话处于前台且有近期活动时，每 20 秒上报一次使用状态。本地统计按对话、小时和学习日聚合，同时记录答题量、学习目标完成和规划任务完成情况。
- 旧版学习页计时保留在数据库，习惯页展示对话使用和完成统计。学习建议在凌晨 4 点换日，自动生成时使用近 14 天摘要和已缓存的地区、天气、节假日。在「规划 → 设置 → 通用设置」手动保存新地区会加刷一次建议。

## 3. 旧计划模型（保留，勿扩展）

- 表：`subjects`（科目，可带考试日）、`topics`（知识点，掌握度 0–10 存 TEXT，含 `lock_until` / `mastered_at`）、`study_plan`（某天·某知识点或自由任务·学/复习·分钟数·镜像任务 id）。
- 原有计划条目继续显示。自动生成科目计划已停用，可以为学习任务直接设置开始时间。
- 完成联动：`study_plan_done` 关闭计划行、关闭镜像任务、知识点掌握度 +1，并按**更新后的掌握度**排下次复习：

| 更新后的掌握度 | 下次复习 |
|---|---|
| ≥10 | 不再复习 |
| ≤2 | 1 天 |
| 3–4 | 2 天 |
| 5–6 | 3 天 |
| 7–8 | 5 天 |
| 9 | 7 天 |

（旧文档写的"0 → 每天出现"与代码不符：代码里 0 落在 1 天档。"降到 0 冷却 3 天"在旧轨确实存在——`setMastery` 写 `lock_until`，冷却期内掌握度不允许上升；新轨则按知识库行的 `updated_at` 判断。规则相同，载体不同。）

## 4. 取舍与已废弃表述

**为什么保留两套**：旧轨是"科目到考期的日程铺排"，新轨是"工作区里的知识库 + 每日出题"。把它们合并会牵动数据迁移与页面结构，收益不足，故冻结旧轨、新功能只加新轨。

以下说法**已废弃**，不要在文档或对话里继续使用：

- ❌ 首次创建学习模式对话时自动生成学习任务 —— 改为对话显式 `study_register_task`，或页面登记。
- ❌ 对话标题自动同步为任务标题 —— 只在登记时取当时的标题，之后不跟随。
- ❌ 学习页只有 4 个分区 —— 现在 5 个（多了「习惯」）。
- ❌ `topics.mastery` 应为 INTEGER —— 实际是 TEXT 存 `'0'`–`'10'`，读取时统一转数字。
- ❌ 知识数据存插件库 —— 知识在会话工作区 `knowledge.db`，插件只存索引。
- ❌ 学习任务需要用户手动勾完成 —— 由对话与每日目标驱动。

## 5. 门控

学习工具与学习页数据受三层开关约束，规则集中在《[工具与路由](./工具与路由.md)》第 3 节：会话标题栏开关、`study-teach` 预设自动授权、插件 Config 的 `studyMode` / `studyPanel`。

## 6. 默认参数

| 参数 | 默认 |
|---|---|
| 每轮题量 | 5 题（允许 5–10，接口上限 20） |
| 每日目标 | 新 5 + 复习 10；每段 0–200，合计 > 0；当日覆盖可单段为 0 |
| 初始熟练度 / 范围 | 4 / 0–10 |
| 熟练度 0 | 仍每天出题，3 天内答对不加分 |
| 满 10 处理 | 视为掌握、不再出题、删对应错题 |
| 旧轨日容量 | `studyDailyMinutes` = 60 分钟（每周计划优先） |
| 旧轨估时 | 学习 45 分钟（掌握度 >4 时 30）/ 复习 15 分钟 |
| 学习日切分 | 04:00 |
