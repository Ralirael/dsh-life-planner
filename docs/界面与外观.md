# 界面与外观

适用版本：`plugin/package.json` = **0.9.37** ｜ 2026-11-15
界面分两个侧边栏入口（规划 / 学习），共用同一套样式令牌与外观模型。规则冲突时以《[需求台账](./需求台账.md)》为准。

## 1. 规划页 5 个视图

入口：侧边栏「规划」（槽位 `sidebar.panellist` id `life-planner`，主面板 key `life-planner`）。页签顺序固定（`src/client/panels/planning.js:320-324`）：

| 页签 | 作用 |
|---|---|
| 日历 | 月历、当天安排和长期任务。宽面板并排显示月历与当天安排，窄面板纵向排列。日期格按当天最高优先级淡染 |
| 工作树 | 以**类别**为第一层，类别头可折叠、可 `+` 新建、可拖拽调层级与顺序 |
| 看板 | 待办 / 进行中 / 被阻塞 / 已完成四列 |
| 规划书 | Markdown 规划书，agent 可通过 `planner_update_plan` 改写 |
| 已归档的任务 | 剪枝后的归档树，可恢复；恢复后跳回工作树并定位 |

## 2. 学习页 5 个分区

入口：侧边栏「学习」（id `life-planner-study`，主面板 key `life-planner-study`）。页签顺序（`src/client/panels/study.js:49-55`）：

| 分区 | 作用 |
|---|---|
| 今日学习 | 今日计划进度、待复习知识点和到期错题优先显示。今日建议可展开，学习任务两段目标在「学习规划」 |
| 学习规划 | 旧计划模型：科目 / 知识点 / 掌握度 / 生成与重排计划；下方「学习任务」区展示本周计划分钟与每日新/复习进度（只读） |
| 书架 | 文件 / 递归目录 / 网址，打标签、刷新、打开；目录列表上限 800 项，超出标「已截断」；可挂到学习任务；删除需确认 |
| 错题集 | 题目、正确答案、错误原因、来源；默认随机排序，筛选后按创建时间倒序，双击放大，可删除 |
| 习惯 | 近 14 天学习时长与连续天数；本周时间表**只读**，由学习对话写入 |

学习页可见时每分钟发一次心跳（`habit.beat`）累计学习时长，切到其它页面或最小化即停止。

## 3. 设置 4 个页签

设置弹窗标题带版本号（与 `package.json` 一致）。页签固定 4 个（`src/client/dialogs/settings.js:869`）：

| 页签 | 内容 |
|---|---|
| 分类与标签 | 任务类别库（含颜色、内置不可删）、标签库；只维护列表，不改既有任务 |
| 通用设置 | 提醒窗口、提前量、间隔、配额、顺延、归档/删除天数、系统通知开关、学习分钟数 |
| 通知设置 | 权限申请、测试通知、系统通知偏好 |
| 外观与皮肤 | 皮肤预设与命名保存、8 档字号、日历高度、分区主题色、面板透明度、背景与蒙版 |

## 4. 字号：8 档令牌

8 个令牌就是 8 档（`src/client/appearance.js:8`，设置界面按日历页从上到下的顺序排列：`settings.js:796-803`）。**单位统一为像素**，改动即时生效。

| 令牌 | CSS 变量 | 默认值 | 影响 |
|---|---|---|---|
| 页签 | `--lp-tab-fs` | 13px | 视图页签文字 |
| 标题 | `--lp-title-fs` | 15px | 弹窗标题、列头、日期标题 |
| 日历 | `--lp-cal-fs` | 12px | 日历格子内数字与计数 |
| 任务行 | `--lp-task-fs` | 13px | 树行、卡片、看板卡片 |
| 类型 | `--lp-type-fs` | 11px | 类别胶囊、分组头 |
| 标签 | `--lp-tag-fs` | 12px | 标签胶囊、筛选 chip |
| 辅助 | `--lp-meta-fs` | 11px | 时间、计数、说明文字 |
| 基础 | `--lp-fs` | 13px | 其余正文；派生出 `-1px` 与 `-2px` 两档小字和 `+2px` 大字 |

派生规则（不用手算）：任务行高 = 任务行字号 + 17px，标签高度 = 标签字号 + 10px，日历高度取设置值，`0` 表示用默认 420px（`appearance.js:273-275`）。

## 5. 面板透明度

- 默认 **15%**（`appearance.js:12`），滑块范围 0–0.6，步长 0.05（`settings.js:844-859`）。
- 含义：面板底色保留 `(1 - 透明度)` 的不透明度，所以 15% 表示"面板 85% 不透明"，背景图能透出来一点。
- **只在背景模式为「图片」时生效**；无背景或纯色时面板是不透明的（`appearance.js:285-292`）。
- **弹窗不受面板透明度影响**：设置、新建/编辑任务、书架/科目/错题弹窗与确认卡使用独立令牌
  `--lp-modal-bg`（图片背景时约 **97% 不透明**），并把遮罩加深到 `rgba(0,0,0,.58)`，
  避免底层内容干扰阅读与输入。控件（输入框、下拉）仍用 `--lp-control-bg`（约 47%），
  因为它们叠在近乎不透明的弹窗上，需要靠描边与模糊区分。

## 5.1 无边框窗口拖动

- 页头 `.lp-head` 设 `-webkit-app-region: drag`；页签、按钮、输入框与下拉设 `no-drag`。
- 效果：macOS 无边框窗口下，插件页顶部的空白区域（包括页签之间的间隙）可拖动窗口，
  点击页签仍能切换；带原生标题栏的 Windows 不受影响。

## 5.2 日历折叠

- 月历右上角可手动切换月历和周栏。
- 窄面板向下滚动时自动折叠，周栏吸顶。回到顶部后继续向上滚动会重新展开月历。
- 规划和今日学习的界面过渡遵循系统的减少动态效果设置。

## 6. 背景：三模式 + 蒙版

规划页与学习页各一套配置（`settings.js:416-551` 渲染，`appearance.js:279-305` 应用）：

| 参数 | 取值 | 默认 |
|---|---|---|
| 模式 | 无 / 纯色 / 图片 | 图片（内置默认背景） |
| 纯色 | 颜色选择器 | `#1b1e24` |
| 内置默认图 | `plugin/assets/default-background.webp`（1920×1080 webp，约 109 KB），随安装包分发 | 两个区域都指向它 |
| 图片不透明度 | 0–0.9，步长 0.05 | 0.35 |
| 蒙版开关 | 开 / 关 | 关 |
| 蒙版方向 | 左 / 右 / 上 / 下 | 左 |
| 蒙版宽度 | 5%–90%，步长 5 | 25% |
| 蒙版强度 | 0.1–1，步长 0.05 | 0.35 |

- 蒙版是一层从所选边缘向内渐隐的底色：`linear-gradient(方向, 底色@强度 0%, 透明 宽度%)`（`appearance.js:141-149`）。
- 内置默认图由 `GET /life-planner/api/background?area=default&v=1` 提供（无需用户上传），用户上传的图仍存在插件数据目录 `backgrounds/`，由 Host 以带版本号的 URL 提供（版本化 URL 可长期缓存），客户端再 `fetch → blob` 加载；纯 CSS `url()` 带不上请求头，桌面壳里加载不到。
- 换图/清空图走 `background.set` / `background.clear`；`background.info` 返回当前目录与两张图的 URL。

## 7. 皮肤与默认

- 下拉里只有两类选项：**默认**（`builtin:default`）与**用户命名皮肤**（`user:<名字>`）。内置的 `compact` / `large` 令牌皮肤代码仍在（`skins.js:5-37`），但已不出现在下拉里。
- **命名保存**：把当前外观 + 皮肤存成一份快照，名字 ≤24 字（`appearance.js:355-363`）。
- **设为默认**：把当前外观记为"我自己的默认基线"，此后重置或换皮肤都从这里出发（`appearance.js:85-88`）。
- 还支持导出/导入外观 JSON、删除当前用户皮肤（`settings.js:746-789`）。
- 切换皮肤会用整份快照覆盖字号、透明度、背景与令牌，因此**先保存再切换**，否则未保存的微调会丢。

## 8. 持久化位置

| 内容 | 位置 |
|---|---|
| 外观（字号、透明度、背景、蒙版）与用户皮肤 | 宿主 `ui_state` 表：`appearance` / `skins` 两个键；`GET ui` 读取，`ui.save` 写入 |
| 首帧缓存 | 浏览器 localStorage：`lpAppearance.v1`、`lpUserSkins.v1`、`lpSkin`、`lpDefaultAppearance.v1` |
| 背景图片文件 | `$DSH_HOME/life-planner/backgrounds/` |

读取优先级：宿主值 → 本地缓存 → 内置默认值。写入时机：任何外观变更后 400ms 防抖写 `ui.save`（`appearance.js:44-57`）。这样换端口、重启、换 origin 都不丢。

## 9. 已知交互约定

- **设置页签不随字号变化**：设置弹窗的页签固定 13px 并换行而不是横向滚动（`skin.js:257-259`），其它页签才跟随 `--lp-tab-fs`。
- **输入框跟随区块**：输入框、按钮、下拉统一用基础字号 `--lp-fs`（`skin.js:264-267`），不单独设字号。
- **图标不缩放**：`Icon` 固定 18px（可用 `size` 覆盖），不参与 8 档字号（`ui.js:2`）。
- **页签高度自适应**：高度由 `--lp-tab-fs + 16px` 推导，字号调大时页签变高并保留横向滚动条。
- **设置字段是响应式网格**：`auto-fit` + 最小 190px，窄窗口自动折行，不出现横向滚动。
- **深浅色跟随宿主**：颜色全部取 `--dsw-alias-*` 品牌/底色令牌，不写死颜色，主题切换无需重载。
