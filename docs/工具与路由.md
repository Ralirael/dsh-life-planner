# 工具与路由

适用版本：`plugin/package.json` = **0.9.37** ｜ 2026-11-15
共 **43 个工具**（宿主冒烟断言的总数，`plugin/index.js` 的 `buildTools`），接口前缀 `/life-planner/api`。改工具名或路由名要同步本表与冒烟脚本。

## 1. 工具（按前缀分组）

### `planner_*` — 规划书与整体摘要（4）

| 工具 | 作用 |
|---|---|
| `planner_overview` | 计划摘要：各状态桶计数，加逾期/今天/3 天内/被阻塞各最多 20 条带 id |
| `planner_get_plan` | 读规划书 Markdown 全文 |
| `planner_update_plan` | 整篇替换规划书（需用户确认措辞后调用） |
| `planner_reset` | 清空数据：`scope=tasks` 只清任务树/规划/计划/通知，`all` 再加科目/知识点/错题/书架/学习任务；设置与习惯保留；必须 `confirm=true` |

### `item_*` — 任务树节点（6）

| 工具 | 作用 |
|---|---|
| `item_add` | 建任务；类别缺省时由顶层祖先标题推导 |
| `item_update` | 改标题/备注/状态/优先级(0–9)/起止/地点/父级/标签/类别 |
| `item_move` | 移到另一个父级，或移回根 |
| `item_archive` | 归档已完成任务，离开活动列表但可恢复 |
| `item_delete` | 删除任务；子节点上移一级，5 分钟内可撤销 |
| `item_reorder` | 在同级里上移/下移 |

### `task_*` — 完成与依赖（2）

| 工具 | 作用 |
|---|---|
| `task_complete` | 标记完成或撤销；有未完成子任务/前置时返回阻塞清单，用户同意后才带 `force` |
| `task_depends` | 替换前置任务列表；有环直接拒绝 |

### `study_*` — 学习（30）

| 工具 | 作用 |
|---|---|
| `study_overview` | 旧轨概览：科目、知识点、待复习 |
| `study_add_subject` | 建科目（考试日可选） |
| `study_update_subject` | 改科目；空考试日 = 无考试 |
| `study_add_topic` | 在科目下加知识点，掌握度默认 4 |
| `study_set_mastery` | 设知识点掌握度，并按规则排下次复习 |
| `study_record_sources` | 为知识条目登记书架资料、PDF 或印刷页和章节位置 |
| `study_plan_today` | 今日计划项（返回 `{ entries }`） |
| `study_plan_done` | 完成计划项：关任务、涨掌握度、排复习 |
| `study_link_materials` | 给计划项挂书架资料（覆盖原列表） |
| `study_register_task` | 登记本会话的学习任务：标题、工作区绝对路径、类型（list/tree/bank/custom）、每日目标 |
| `study_task_list` | 列已登记任务：工作区、模板、资料、逾期天数、今日两段目标与完成数 |
| `study_set_summary` | 回写轻量摘要，页面据此显示进度 |
| `study_run_program` | 在学习任务工作区内跑一段 ESM 程序——批量写 `knowledge.db` 的唯一通道 |
| `study_progress` | 返回按日的两段目标历史（target/answered/newMet/done）与 `doneDays`/`streak`，周检查的判定数据源 |
| `study_next_questions` | 取题分两池：新内容 `learned=0`（随机）与复习 `learned=1`（熟练度升序）；默认按今日两段目标配比，可用 `newCount`/`reviewCount` 覆盖；0 分照常出题但 3 天内答对不加分 |
| `study_answer` | 按正确、错误或部分正确记录一题；返回 `isNew`/`locked`；两段目标都达标才自动完成今天 |
| `study_set_target` | 设默认每日目标：`dailyNew` 与 `dailyReview` 分开（只给一个数时按 1/3 新、2/3 复习拆） |
| `study_set_day_target` | 只改今天（`newTarget`/`reviewTarget`），优先于默认值 |
| `study_finish_today` | 提前标记今天完成（完成镜像节点、清逾期计数） |
| `study_time_plan` | 读本周每天计划分钟数与实际分钟数 |
| `study_set_time_plan` | 写本周计划；`minutes=null` 清空当天 |
| `study_habits` | 近 14 天学习时长、段数、连续天数、完成率 |
| `study_shelf_add` | 书架加本地文件、递归目录或网址 |
| `study_shelf_list` | 列书架条目，用于推荐资料而不是问用户要路径 |
| `study_shelf_delete` | 删一个书架条目 |
| `study_attach_shelves` | 给学习任务挂书架资料（覆盖原选择） |
| `study_import_material` | 把书架文件/目录复制进工作区 `learning/materials/` |
| `study_pdf_text` | 用 pdftotext 抽工作区内 PDF 文本，可落文件避免长文进上下文 |
| `study_read_file` | 读工作区内的文本文件（有字符上限） |
| `study_template` | 取内置模板正文（list/tree/bank/custom，以及辅助文档 ingest/teaching） |
| `study_mistake_add` | 记错题；带 `taskId` + `itemId` 才能在满 10 时自动清理 |

## 2. 路由（`/life-planner/api`，按 method 分组）

所有响应是 `{ ok, data }` / `{ ok:false, error }`；未知方法 404，异常 400（`dev.scan` 在非开发模式返回 404）。

### GET（16）

| 路径 | 返回 |
|---|---|
| `snapshot` | 任务树快照（含派生状态）+ 规划书 |
| `session?sessionId=` | 该会话工具开关状态 |
| `ui` | `{ appearance, skins }`——外观与用户皮肤的宿主副本 |
| `settings` | 设置全量（缺省值合并；库为空时会先播种标签） |
| `notifications` | 待投递提醒 |
| `export` | 全量导出 JSON |
| `config` | 运行时插件开关 |
| `learning` | 旧轨：科目/知识点/计划/错题 |
| `study-tasks` | 学习任务索引列表 |
| `habits` | 近 14 天习惯摘要 |
| `study-time?week=` | 一周的计划与实际分钟 |
| `shelf` | 书架条目 |
| `mistakes` | 错题集 |
| `tip` | 今日提示 |
| `background?area=planning\|study[&v=]` | 背景图二进制（`area` 白名单，版本化 URL 可长缓存） |
| `background.info` | 背景目录与两个区域的图片 URL |

## 3. 门控规则

工具注册时带 `when({ agent })`，同一条规则覆盖 43 个工具：

1. **插件级 `studyMode=false`** → 所有 `study_*` 工具一律不可见（学习功能整体停用，改后需重启插件）。
2. **会话开关** → 否则看该会话的 `session_flags` 记录：键优先取 `agent.session.id`，没有才回退 `agent.id`；没有记录即关闭。页面标题栏的开关就是写这一条。
3. **`study-teach` 预设自动授权** → 若是学习模式会话（`presetForSession(session) === 'study-teach'`），无需先开开关即可用工具；新会话创建时插件还会顺手把该会话标记为已开启，使页面立即可见。

路由侧另有两道：

- `connection.requestRejection(req)` 命中的请求直接 403（来源校验由宿主做）。
- **插件级 `studyPanel=false`** → 学习类 GET（`learning` / `study-tasks` / `shelf` / `mistakes` / `tip` / `habits` / `study-time`）与学习类前缀 POST（`mistake.` / `shelf.` / `plan.` / `topic.` / `subject.` / `studytask.` / `study-time.` / `data.`）返回**空结构**而不是报错，页面因此显示空状态。外观、设置、快照等不属于学习面板，不受影响。

`dev.scan`（手动触发一次提醒扫描）只在 `LIFE_PLANNER_DEV=1` 时可用。
