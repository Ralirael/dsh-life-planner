### 清零的文档债务

- 不再有"两份文档同时自称当前依据"：现行依据只有本目录这几份。
- 文档里不再出现旧版本号（0.2.6 / 0.3.3）与旧工具数（9 / 20 / 21 / 42）：工具数固定为 **43**（冒烟断言），版本以 `package.json` 为准。
- 旧的三级类型模型、早期"自动建任务"与"标题跟随"等结论，只保留在历史文档与《学习模式》的已废弃清单里，现行文档不再复述。

### 仍然存在的债务

- `plugin/README.md` 与根 README、`docs/架构与数据.md` 的目录树仍有重复（内容已一致，但改一处要记得改三处）。
- 《需求台账》的证据行号是 v0.9.37（2026-11-15）快照：代码改动后行号会漂移，请按括号里的函数名/锚点搜索。- `docs/audit/` 里的历史条目保留原文，不随代码更新。

## 4. 维护约定

- 改代码 → 先改《需求台账》状态列，再改对应专题文档，最后在 [CHANGELOG](./CHANGELOG.md) 记一条。
- 新写文档放本目录，首行写清"状态 / 适用版本 / 关联文档"，不放进 `archive/`。
- 任何文档的"版本""工具数""分区数"都必须能指向代码或 `package.json`；写不出来就别写数字。
