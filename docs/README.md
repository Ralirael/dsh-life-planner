## 3. 维护约定

- 改代码时同步更新：[需求台账](./需求台账.md) 的状态列、[工具与路由](./工具与路由.md) 的名称表、
  [CHANGELOG](../CHANGELOG.md) 的版本条目；其余文档只写一处，其余链接过来。
- 版本、工具数、视图/分区数一律从代码或 `plugin/package.json` 取，不手写猜测。
- 文档里的证据行号是快照；代码改动后按"文件 + 函数名"搜索，不要死记行号。
- 新增文档放本目录，首行写清"适用版本 / 状态 / 关联文档"。
- 发布前运行 `node plugin/test/tools/privacy-scan.mjs <发布目录>`，确认没有本机路径、用户名或凭据。
