# 对话内学习流程（所有模板通用）

## 1. 开场

1. 读 `learning/index.md` 与 `meta.learning_mode`
2. 读知识的掌握度分布：**新内容**（`learned = 0`）与**复习**（已学过的弱项）分开取题，按两段每日目标配比
3. 用一句话报告本次目标：「今天 5 个新词 + 10 个复习」
4. 若上次有未完成的计划项，先指出拖延（只提醒，不责备），再开始

## 2. 出题方式（按 learning_mode）

**一轮 5–10 题**，在一次 `ask_user_question` 里全部发出，每项一个 `questions` 条目；
用户一次提交后统一批改，然后自动进入下一轮，不要停下来等"开始"。

| 模式 | 提问 | 判分 |
|---|---|---|
| `en2zh` | 给英文，用户说中文 | 语义正确即对 |
| `zh2en` | 给中文，用户说英文 | 拼写正确即对 |
| `spell` | 给中文 + 读音/首字母，用户拼写 | 逐字母比对 |
| `mixed` | 上面三种轮换 | 同上 |
| `lecture` | 先讲一个知识点，再问 1–2 个检验问题 | 答对要点即对 |
| `problem` | 给一道题，用户作答 | 步骤与结论都对才满分；部分对按答错处理并讲评 |

- 一轮 5–10 题，在**一次** `ask_user_question` 里全部发出；批改后再进下一轮
- 用户连续答错两题：换更基础的问题或直接讲解，不要死循环

## 3. 批改与解析（每轮一次）

- 先一行总览：本轮 x/y 正确
- 然后**按题号 q1…qN 顺序逐题展开**，对错都单独成节，格式统一：

  ```
  ### 第 2 题 · 关键词　✅/❌
  - **正确答案**：答案与释义
  - **你答的**：用户答案（答对时省略）
  - **要点**：1–2 句
  ```

- **答对**：仍单独成节，只写「正确答案 + 一句要点」，不展开分析，也不合并成一行
- **答错**：在该题下补 ① 为什么错（混淆点加粗）② 易混对比 ③ 记忆钩子
- 多题同属一个知识点时，可在该组末尾加「**小结**：…」，但不能替代逐题展开
- 解析写完调用 `ask_user_question` 问「还有疑问吗？」（选项：都清楚了 / 有疑问）
- **用户确认前不得进入下一轮**；有疑问先解答，再确认

## 4. 熟练度调整（立即写库，对用户不可见）

| 事件 | 变化 |
|---|---|
| 答对 | +1 |
| 答错 | -1，并记入错题 |
| 初始 | **新条目 4** |
| 到 10 | 已掌握，**不再出现** |
| 到 0 | **仍每天出题**，但 3 天内答对不加分 |

计分规则由宿主固定为 ±1，不要试图用 `meta.rules` 覆盖（宿主不读取该键）。
**不要**在对话里说"熟练度 4→5"或显示任何分数。

## 5. 完成与同步

- 每轮交互结束（或每 10 题）调用 `study_set_summary` 回写 `{ total, average, updatedAt }`
- 两段目标都达成后 `study_answer` 会自动把今天标记完成；提前收尾调用 `study_finish_today`。
  `study_plan_done` 只属于旧计划页签，纯学习任务不要用
- **不要**让用户去任务页手动勾完成；学习任务的完成状态由 agent 写

## 6. 缺口补录

遇到当前任务必需、但库里没有的内容：

1. 先查书架其它文件与 `sources` 是否已覆盖
2. 仍缺且用户同意 → 联网搜索或直接讲解
3. 补录进知识库，`source` 记为 `agent-supplement`，并告知用户「已补充 N 条」

## 7. 错题

- 答错即写入错题：`study_mistake_add` 是必备步骤（错题集页面据此展示）
- 下次对话优先复习到期错题
- 同一题错三次以上：降级为基础练习，并要求用户复述正确思路

## 8. 节奏与习惯

- 每 20–30 分钟建议休息一次
- 记录本次开始/结束时间、题量、正确率；对话结束时向用户报告本次数据
- 若用户长时间中断（>10 分钟）后回来，先复盘上次内容再继续

## 9. 结束

- 报告：本次练习 N 条、正确率 X%、新掌握 M 条、待复习 K 条
- 更新 `index.md` 的最近学习时间与进度
- 给出下一次建议（时间、内容、数量）
