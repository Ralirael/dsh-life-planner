# 资料入库流程（所有模板通用）

> 目标：把书架资料变成知识库条目，并保证**可增量、可去重、可追溯、可复用**。

## 1. 签名

对每个文件计算：

```
signature = md5(文件内容) + ":" + 字节数 + ":" + 修改时间(ISO)
```

- 目录：递归列出全部文件，逐个算签名
- 网址：`signature = md5(URL) + ":" + 抓取时间`（内容变化才需要重新抓）
- 签名与 `path` 一起写进 `sources` 表；`path` 用相对 `materials/` 的路径保证可移植

## 2. 判断要不要处理

| 情况 | 动作 |
|---|---|
| `sources` 中无该 path | 新文件 → 全量提取 |
| path 存在且签名相同 | 跳过，只更新 `checked_at` |
| path 存在且签名不同 | 增量：只补新增/变化的条目，已存在条目保留熟练度 |
| path 存在但 `extracted` 缺类型 | 补齐所缺类型（如只提了单词，缺例句） |
| 文件已从书架移除 | 不删条目，只把 `source` 标记为缺失 |

`extracted` 是一组类型标记，例如 `["word","example","phonetic"]`；缺什么补什么。

## 3. 省 token 的复用

处理某个签名前，先扫**其它学习任务工作区**的 `sources`：

1. 命中同签名 → 直接复制对方的条目（按模板去重后），本方只记 `sources`
2. 命中同 path 不同签名 → 走增量，不要全量重读
3. 都没有 → 才读文件本体

复用时要保留来源链：`meta.reused_from = <原任务工作区>`。

## 4. 提取与去重

- 单词库按 `front` 去重；大纲按 `(chapter_id, title)` 去重
- 已存在的条目：只补 `source` / `section` / `extra` 中为空的字段
- **绝不覆盖已有熟练度**
- 初始熟练度：新条目一律 4（与 `word-bank` 一致；不要写 0，0 只是 3 天内答对不加分，条目仍每天出题）

## 5. 写回

1. 事务内写条目与 `sources`
2. 更新 `meta.last_update`、`meta.count_<类型>`
3. 调用 `study_set_summary`：`{ total, average, updatedAt }`
4. 在 `index.md` 更新目录（来源清单 + 条目数 + 最近更新）

### 书架定位

- 给关联书架的条目调用 `study_record_sources`，每条记录带表名、知识条目 id 和 shelfId。目录资料补相对文件名，网页使用原网址并补章节或锚点，纸书记录印刷页，PDF 记录从 1 开始的文件页。
- 使用 `study_pdf_text(numbered=true)` 保留 PDF 页边界。PDF 文件页和印刷页分别记录。来源无法核实时留空，不猜测页码。
- 可以为同一知识条目保存多个来源。复用资料时保留原始出处。移除书架或更新插件均无需删除知识条目。

## 6. 触发时机

- 用户在学习页刷新书架，或对话里说"更新资料"
- 每周一次自动检查（对话内由 agent 发起）
- 首次挂载书架

## 7. 边界情况

| 情况 | 处理 |
|---|---|
| 文件读不了（权限/格式） | 记 `sources.extracted=[]` + 错误原因，下轮重试 |
| 文件过大（>2MB 纯文本） | 分段提取，记录已处理偏移 |
| 编码乱码 | 尝试 utf-8 / gbk，仍失败则跳过并记录 |
| 用户中途卸载书架 | 保留条目与来源标记，不删数据 |
