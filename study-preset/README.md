# 学习模式预设（study-teach）

一个 DSH 预设包，把助手切换成"学习模式"：先确认学习需求，再讲解、检验、记录掌握度。

安装后预设列表里显示为「**学习模式**」（id `study-teach`）。

## 安装

1. 打开「插件」页
2. 添加插件 → 选择本目录 `study-preset`
3. 安装并启用

安装会在 profile 中插入 `preset-study-teach` 行。**新开会话**才能在预设里选到「学习模式」——已存在的会话沿用启动时的插件版本。

## 它做什么

- 人格：耐心的讲解者，先直觉后定义再举例；一轮 5–10 题，在一次提问里问完再统一批改
- 工具：预设自带一套内置工具集（文件、命令、网页、Office 等）；插件工具（任务 12 个 + 学习 31 个，共 43 个）
  由**会话标题栏开关**控制，`study-teach` 会话默认自动授权
- 该模式下助手会维护学习页的数据：登记学习任务、建科目、记录掌握度、整理错题、按周规划学习时间

## 与学习页的关系

预设负责"怎么教"，学习页负责"学什么、排到哪天"。数据分两层：

- **索引与摘要** → 插件数据库 `~/.dsh/life-planner/data.db`（学习任务、科目、掌握度、错题索引）
- **知识库本体** → 会话工作区 `learning/knowledge.db`（单词卡/知识点，含熟练度与来源），平时只读，
  只有 `study_run_program` 执行期间临时解封
- 掌握度 0–10（初始 4），**由对话维护，页面上只读**；满 10 视为掌握，不再出题并自动移出错题
- 熟练度为 0 的条目**仍每天出题**，但 3 天内答对**不加分**（锁定以知识库行的 `updated_at` 计）；满 10 后不再复习
- 每日目标分**新内容**（`learned=0`）与**复习**（已学过的弱项）两段，两段都达标才算今天完成
- 学习计划按周规划：学习页展示的时间表由对话用 `study_set_time_plan` 写入，用户不手工填写

## 卸载

在插件页移除该 bundle 即可；插件数据库与各会话工作区里的 `learning/knowledge.db` 都不会被删除。
